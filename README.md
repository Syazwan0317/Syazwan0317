## 📖 About The Project

This project was developed as part of the **CSD34203 Special Topics in Software Development** course.

The website serves as a personal portfolio and blogging platform where visitors can:

- Learn more about me
- Explore my technical skills
- Read blog articles
- Contact me professionally

The project demonstrates web development fundamentals while applying entrepreneurial concepts such as creativity, initiative, value creation, and problem-solving.
